# Retail Banking SQL Project

## Project Overview

This project focuses on analyzing retail banking data using **MySQL and SQL**. The objective is to explore customer, account, branch, transaction, and banking-related data and generate meaningful business insights through SQL queries.

## Project Files

| File | Description |
|---|---|
| `bank_retail.sql` | Complete MySQL database setup, table creation, data handling, and SQL analysis queries |
| `Retail_Banking_Transaction.pptx` | Project presentation containing the project overview, analysis, and findings |

## Objectives

- Analyze retail banking customer and account data
- Analyze banking transactions and identify useful trends
- Perform data filtering, aggregation, and sorting
- Use joins to combine information from multiple tables
- Apply subqueries and derived tables for analysis
- Use CTEs for complex queries
- Use window functions for advanced analysis
- Create views for reusable analysis
- Apply CASE statements and date functions
- Generate business-oriented insights from banking data

## Tools & Technologies

- **Database:** MySQL
- **Language:** SQL
- **Database Tool:** MySQL Workbench
- **Version Control:** Git & GitHub
